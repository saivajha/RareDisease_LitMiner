# RareDisease LitMiner

A RAG-based scientific literature mining application for rare disease researchers. Search PubMed, index articles, and ask AI-powered questions with full citations.

---

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│                   React Frontend (Vite)                  │
│  SearchPanel | QueryPanel | ArticleList                  │
└─────────────────┬───────────────────────────────────────┘
                  │ HTTP /api/*
┌─────────────────▼───────────────────────────────────────┐
│                 FastAPI Backend                          │
│  /api/search  →  PubMed E-utilities → PostgreSQL         │
│                                     → ChromaDB          │
│  /api/query   →  ChromaDB (RAG retrieve)                │
│                → Anthropic Claude (generate)            │
│  /api/articles → PostgreSQL                             │
└────────────┬──────────────┬────────────────────────────┘
             │              │
    ┌────────▼───┐  ┌───────▼────────┐
    │ PostgreSQL │  │   ChromaDB     │
    │ (metadata) │  │ (vector store) │
    └────────────┘  └────────────────┘
```

## Prerequisites

- Docker & Docker Compose (recommended), **or**
- Python 3.11+, Node.js 20+, PostgreSQL 16, ChromaDB
- NCBI API Key: https://www.ncbi.nlm.nih.gov/account/
- Anthropic API Key: https://console.anthropic.com/

## Quick Start with Docker

```bash
# 1. Clone / enter the directory
cd RareDisease_LitMiner

# 2. Copy and fill in your API keys
cp .env.example .env
# Edit .env and set NCBI_API_KEY and ANTHROPIC_API_KEY

# 3. Start all services
docker-compose up --build

# 4. Open the app
open http://localhost:3000
```

The backend API docs are at http://localhost:8000/docs

## Manual Setup (Without Docker)

### 1. PostgreSQL

```bash
createdb litminer
```

### 2. ChromaDB

```bash
pip install chromadb
chroma run --path ./chroma_data --port 8001
```

### 3. Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Copy env file and set variables
cp ../.env.example ../.env
# Edit .env

# Run migrations
alembic upgrade head

# Start server
uvicorn app.main:app --reload --port 8000
```

### 4. Frontend

```bash
cd frontend
npm install
npm run dev
# App runs at http://localhost:3000
```

## Sample Query Flow: Prader-Willi Syndrome / DCCR

### Step 1: Search & Index

1. Open http://localhost:3000
2. Go to the **Search & Index** tab
3. Enter:
   - **Keyword**: `Prader-Willi Syndrome DCCR hyperphagia`
   - **Max Results**: `20`
   - **Fetch Full Text**: checked (if you want PMC full text)
4. Click **Search & Index**
5. Wait for indexing to complete (~30-60 seconds)

### Step 2: Ask a Question

1. Go to the **Ask a Question** tab
2. Enter: `What is the mechanism by which DCCR reduces hyperphagia in Prader-Willi Syndrome?`
3. Click **Ask**
4. The system will:
   - Retrieve the top 8 most relevant text chunks from ChromaDB
   - Send them as context to Claude
   - Return an answer with citations: `[PMID: X | Title: Y | DOI: Z]`

**Expected output**: A detailed answer explaining the diazoxide choline controlled-release mechanism involving hypothalamic pathways, oxytocin modulation, and appetite regulation, citing relevant PMIDs.

## API Reference

### `POST /api/search`
Search PubMed and index articles.

```json
{
  "keyword": "Prader-Willi Syndrome",
  "max_results": 20,
  "date_from": "2020-01-01",
  "date_to": "2024-12-31",
  "journal_filter": "",
  "fetch_fulltext": true
}
```

Response:
```json
{
  "indexed_count": 15,
  "articles": [...]
}
```

### `POST /api/query`
Ask a question using RAG.

```json
{
  "question": "What treatments are available for hyperphagia in PWS?",
  "filters": {
    "journal": null,
    "date_from": null,
    "date_to": null
  }
}
```

Response:
```json
{
  "answer": "Based on the literature... [PMID: 12345678 | Title: ... | DOI: ...]",
  "disclaimer": "DISCLAIMER: Responses generated by this tool are for research support purposes only...",
  "sources": [
    {
      "pmid": "12345678",
      "pmcid": "PMC9999999",
      "doi": "10.1000/xyz",
      "title": "Article title",
      "journal": "Journal name",
      "pub_date": "2023-05-01",
      "authors": ["Smith, J", "Doe, A"]
    }
  ]
}
```

### `GET /api/articles`
List indexed articles.

Query params: `keyword`, `journal`, `date_from`, `date_to`, `page`, `limit`

## Environment Variables

| Variable | Required | Default | Description |
|---|---|---|---|
| `NCBI_API_KEY` | Yes | — | NCBI E-utilities API key |
| `ANTHROPIC_API_KEY` | Yes | — | Anthropic Claude API key |
| `DATABASE_URL` | No | `postgresql://postgres:postgres@localhost:5432/litminer` | PostgreSQL connection string |
| `CHROMADB_HOST` | No | `localhost` | ChromaDB host |
| `CHROMADB_PORT` | No | `8001` | ChromaDB port |
| `CHROMADB_USE_HTTP` | No | `true` | Use HTTP client (vs. persistent local) |
| `EMBEDDING_MODEL` | No | `all-MiniLM-L6-v2` | Sentence-transformers model name |
| `MAX_RESULTS_PER_SEARCH` | No | `20` | Default max PubMed results |
